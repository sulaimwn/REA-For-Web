# Real-world sample projects (T031)

Three small, popular open-source apps, one per kind of target. They're demos of what the site does with
real software. The binaries aren't committed; only REA's output is (`fixtures/samples/*.rea-6.4.0.json`),
regenerated by `fixtures/tools/sample-fixtures.mjs`. Every app was only read by REA, never installed or run.

- **Caprine:** `resources/app.asar` (23 MB) was pulled out of the `.deb` with `dpkg-deb -x` in an offline
  container. Nothing was installed and no package scripts ran. `app.asar.unpacked` (native modules) wasn't analyzed.
- **jq:** collected with REA's Ghidra provider (`native-session`).
- **jq for macOS:** collected the same way, but inside the native worker image, because REA's Ghidra provider reads
  Mach-O only on a Linux or macOS host. The container had no network and the program was mounted read-only. REA reports
  `format: "mach-o"`, `x86_64`, 1,667 functions and 130 imports from `/usr/lib/libSystem.B.dylib`.
  Run `JQ_MACOS=<jq-macos-amd64> node fixtures/tools/sample-fixtures.mjs` (with `REA_SCRIPT` set) after building the native image.
- **Binary Eye:** collected with REA's JADX provider (`android-session`).
- **Uploads come first.** These demos show the kinds of maps the site makes, but the point of the site is
  that people upload their own apps.
