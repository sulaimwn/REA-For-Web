# T015 — Adapter: .asar inputs, fallback name, Electron detection (claude)

**Branch:** `claude/T015-asar-inputs` (from `main` @ `a8ce43d`)
**Status:** review. **Needs Codex's OK on one shared-schema doc change (item 3).**

## Why
The human's real upload of Obsidian (`obsidian.asar`, via T007) showed 72 "analysis gaps", the title
`target.asar` and type `javascript`. Diagnosis from the stored result
(`.pipeline-data/objects/results/.../146ef847….json.gz`):
- 38 gaps were REA `asar-entry` nodes the adapter didn't know (all our fixtures were directories).
- 31 gaps are real REA per-file timeouts (big bundled libraries); 3 are projection failures.
- REA emitted **no package node** for `obsidian.asar` (its package.json's `main: index.js` doesn't exist in that
  archive), so the name fell back to the sandbox path `target.asar`.
- `obsidian.asar` is only the renderer half (the main process is in Obsidian's separate `app.asar`). The adapter only
  said `electron` when it found a *main* process, despite 2 renderers + 1 preload.

## What changed
1. **`asar-entry` support** (`index.ts`, `nodes.ts`). REA's shape is `root --contains--> asar-entry --maps_to--> file`.
   Each entry is folded into the file it maps to: its evidence is appended to that file (`inventory-asar-entry`),
   the root's `contains` points at the file, and the resulting self-edge is dropped. An entry that maps to nothing
   becomes a `file` (`fileKind: 'other'`). `AdapterReport` gains `foldedAsarEntries` and `droppedSelfEdges`.
2. **`AdapterOptions.targetName?`**: used as `target.name` when REA reports no root package.
   **Codex: please pass the uploaded file's original name from the worker** (e.g. `obsidian.asar`).
3. **`appKind: 'electron'` when any Electron process (main/preload/renderer) is found.** This changes the
   documented rule in `packages/schema` (doc comment only; the type is unchanged). Needs Codex's agreement before merge.
4. Fixtures: `sample-apps/tiny-electron.asar` (packed with `@electron/asar`) and
   `samples/tiny-electron-asar.rea-6.4.0.json` (real REA output, paths scrubbed). Docs: ARCHITECTURE mapping row +
   adapter API; fixtures README.
