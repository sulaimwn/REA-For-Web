# T060 — remove access-key controls from the website (Codex)

**Branch:** `codex/T060-remove-upload-key`

## Human request and change

The human wants no access-key field anywhere on the upload website, including
an optional one. Removed the entire input/disclosure, key state, owner-header
submission and unused public/private label prop. This is removal, not CSS hiding.
The form now only asks for the file and runs the configured challenge when
enabled. Public uploads require no user-supplied key. Backend operator CLI access,
origin checks, private job tokens, quotas, disk guards and sandbox stay intact.
