# T016 — Ask: question answering over a project (claude)

**Branch:** `claude/T016-ask` (built on `claude/T013-local-mode`; merge T013 first)
**Status:** review

## What changed
- **`packages/ask`** (new workspace, `@anthropic-ai/sdk@0.128.0` pinned; published 2026-09-22):
  - `tools.ts`: 5 read-only, size-capped tools over one `StudioProject`: `project_overview`, `search_nodes`,
    `get_node`, `get_neighbors`, `find_path` (BFS, ≤8 hops, ignores the artifact root). `strict: true` schemas.
  - `agent.ts`: `askProject({ client, project, question, model?, maxToolRounds?, signal?, onStep? })`. Manual tool loop
    (needed for per-step UI events and a hard round cap). Per the claude-api skill: default `claude-opus-5-5`
    (Sonnet 5.5 / Haiku 5.5 selectable), `effort: medium` set explicitly, top-level `cache_control`,
    `fallbacks: "default"` + `server-side-fallback-2026-07-01` on Opus/Sonnet, refusal → `AskDeclinedError`.
    Forced `tool_choice` 400s on these models, so the last round appends a mid-conversation system note and
    `tool_choice: none`. `citedNodeIds` keeps only ids that exist. `describeAskError` maps typed SDK errors.
  - `prompt.ts`: short, byte-stable system prompt. Grounded claims only, "not found ≠ absent", heuristic links
    labeled, nodes cited as `[name](node:<id>)`.
- **Web:** the right pane has **Inspector | Ask** tabs (both stay mounted). `AskPanel` holds a bring-your-own-key form
  (sessionStorage by default; localStorage only with "Remember on this device"; "Forget key"), a model picker,
  suggested questions derived from the project's findings, live steps, a stop button, the answer (`AnswerMarkdown`:
  React elements, no HTML injection, only `node:` links clickable), and a token count with a cost estimate.
  The graph gains a `set` focus mode; answers switch it to "Nodes in the answer". Works in `/open` too.
- Root: `packages/ask` workspace, added to `build:packages`. README "Ask questions" + ARCHITECTURE "Ask".

  preload→handler path avoiding the root). Loop with a scripted fake client (tool results fed back, citations
  validated, usage summed, forced final answer at the round limit, caching/effort/fallback params, refusal).
- Browser (stubbed `api.anthropic.com`, fake placeholder key, no real API calls): suggested question → step
  "Searching for notes:save" → answer with clickable nodes → graph shows the 4-node path. Requests carried
  `anthropic-dangerous-direct-browser-access: true`, `anthropic-beta: server-side-fallback-2026-07-01`, `x-api-key`;
  the second request returned the tool result. Forget key cleared storage. No console errors.
- Root typecheck/build pass; adapter 27, worker 31, CLI 4; `npm audit --omit=dev`: 0 vulnerabilities.
