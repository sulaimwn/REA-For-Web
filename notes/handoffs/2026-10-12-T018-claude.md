## What changed
1. **Next.js 16.4.0 → 16.3.8 (pinned)** in `apps/web`. OpenNext can't boot Next 16.4: every page fails with
   `Unexpected loadManifest(/.next/server/preview-props.json)`. Reproduced here; open upstream issue
   opennextjs/opennextjs-cloudflare#1448 (the fix PR #1428 was closed unmerged). The issue reports 16.3.8 working,
   and 16.3.8 is OpenNext 1.20.8+'s security floor. Move back to 16.4 once a release fixes #1448.
2. `@opennextjs/cloudflare@1.20.10` + `wrangler@4.148.0` (dev deps, exact; 1.20.10 requires wrangler ≥4.148).
3. `apps/web/wrangler.jsonc` (worker `reaforweb`, `nodejs_compat`, assets binding, self-reference service,
   commented `routes` for reaforweb.com), `apps/web/open-next.config.ts` (**read-only static-assets incremental
   cache**: every page is prerendered), `apps/web/next.config.ts` (OpenNext requires one), `public/_headers`
   (immutable caching for `/_next/static/*`), `.gitignore` (`.open-next/`, `.wrangler/`, `.dev.vars`).
4. `/explore/[slug]`: `dynamicParams = false`, so only build-time demos exist and unknown slugs 404 without server rendering.
5. Scripts: `cf:build`, `cf:preview`, `cf:deploy` (Linux/macOS/WSL only; OpenNext doesn't support Windows).
6. `.github/workflows/deploy-cloudflare.yml`: on push to `main`, `npm ci --ignore-scripts` → `build:packages` →
   `cf:build`; deploys only when the `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` secrets exist (otherwise it
   builds only, with a notice). Action SHAs and Node 24.18.0 match `worker.yml`.
7. `docs/deploy-cloudflare.md`: the human's step-by-step (domain, workers.dev subdomain, API token, GitHub secrets,
   custom domain).

## How to verify
- **Linux container** (pinned `node:24.18.0-bookworm-slim` digest, same as the worker): `npm ci --ignore-scripts`,
  `build:packages`, `opennextjs-cloudflare build` → `.open-next/worker.js` + 3.2 MB assets; then `opennextjs-cloudflare
  preview` (local workerd, **no Cloudflare account needed**): `/`, `/explore/tiny-electron`, `/explore/github-desktop`,
  `/projects/*.json` → 200; a missing static file → 404. Before items 1 and 3, pages returned 500 and then 404.
- Windows: root build passes on Next 16.3.8; adapter tests 33 pass; typecheck clean; `npm audit --omit=dev` 0.
- install scripts for esbuild/workerd are still pending npm 11's allowScripts. Not approved; the build and preview work
  without them (`--ignore-scripts`, like CI).
