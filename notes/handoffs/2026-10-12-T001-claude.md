## Verdict
**Feasible, with a narrower promise than the original pitch.**
- On the tiny app, REA recovered 100% of the ground truth except one hop (renderer → bridge),
  with exact file:line evidence and observed/inferred labels.
- On GitHub Desktop (real, webpack-bundled), we get a strong **source-tree explorer** (1,777 original
  files via source maps), main/renderer roles, native add-on and storage inventories. We do **not**
  get the app's own import graph, its BrowserWindows, or named IPC channels. Causes: webpack aliasing
  (`r.BrowserWindow`), dynamic channel names, and a shared result budget that drops relationships in
  139/156 files.
- 82 s, 1.5 GB RAM, 50 MB output (8 MB gzipped) for a 383 MB app. VS Code scale is 30+ min, which
  needs job limits.
