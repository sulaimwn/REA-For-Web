# T037 — Launch polish for reaforweb.com (claude)

**Branch:** `claude/T037-launch`
**Status:** review

## What changed
- **App icons** (Next.js file conventions, no code):
  - `apps/web/app/icon.svg`: 32-unit mark, three linked dots (runtime blue, boundary orange,
    system green: the explorer's layer colours) on the site's ink `#161815`.
  - `apps/web/app/favicon.ico`: 32 px PNG in an ICO container (1,176 bytes).
  - `apps/web/app/apple-icon.png`: 180 px (6 KB).
  - Both rasters were rendered from the SVG with headless Chrome (a throwaway profile) and then
    checked by eye. Redraw them if the SVG changes.
- **Metadata** (`apps/web/app/layout.tsx`): the description now covers every format: Electron,
  Windows/Linux programs and Android APKs. Also added `metadataBase: https://reaforweb.com`
  plus Open Graph and Twitter `summary` cards, so shared links show a title and description.
- **`docs/deploy-cloudflare.md` step 6:** the custom-domain steps now use the dashboard
  (Workers & Pages → reaforweb → Settings → Domains & Routes → Add → Custom domain). The
  `routes` block in `wrangler.jsonc` stays commented out. That avoids needing the
  Zone → Workers Routes → Edit token permission at launch.

## How to verify
- `npm run typecheck -w @rea-studio/web`: clean. `npm test -w @rea-studio/web`: 24 pass.
  `next build`: OK, emits `/icon.svg`, `/apple-icon.png` and `/favicon.ico`.
- Preview (`next start`, 3100): the page head has
  `icon /favicon.ico?…`, `icon /icon.svg?…` and `apple-touch-icon /apple-icon.png?…`. All three
  return 200 with image types. `og:description` is set.
- Cloudflare check image (`docker build -f deploy/linux/Dockerfile.cloudflare-check .`): builds.
  Its Workers-runtime preview serves `/favicon.ico` (static asset), `/icon.svg` and `/apple-icon.png`
  (worker routes), all 200 with image types, plus the three head links. `/`, `/explore/binary-eye`,
  `/explore/caprine`, `/open`, `/upload` and `/projects/jq.json` return 200. `/api/mcp` returns 405 on GET, as expected.
