## What changed
- **`apps/web/public/og-image.png`** (1200×630, 135 KB): the logo, "See how an app is put together." and the
  formats line beside a dark-mode crop of the GitHub Desktop demo, with `reaforweb.com`. It was rendered with
  headless Chrome from a scratch HTML card that uses the site's own font. The wording matches the site
  description ("a map of its parts"), not "every part".
- **`apps/web/lib/site.ts`:** `SITE_NAME`, `SITE_DESCRIPTION` and `shareMetadata(title)` build the full
  Open Graph and X `summary_large_image` set, including the image and its alt text.
  - Used by `app/layout.tsx` and `app/explore/[slug]/page.tsx`. Shared demo links get their own title,
    e.g. "jq (Windows .exe) · REA for Web".
  - Why a helper: Next replaces a parent's `openGraph`/`twitter` objects, images included, when a page
    sets its own. With the `app/opengraph-image.png` file convention, explorer pages lost `og:image`.
- **Dropped `og:url: "/"`.** It pointed every shared explorer link at the homepage.
- **README:** the title is now "REA for Web" (it still said "REA Studio") with "Try it at reaforweb.com".
  - Status says uploading to the hosted site isn't open yet.
  - Credits add Caprine 2.61.0, jq 1.8.2 and Binary Eye 1.75.5 (all MIT, per `fixtures/sample-apps/real-world.md`).
