# T013 — Local mode: analyze on your machine, open in the browser (claude)

**Branch:** `claude/T013-local-mode` (from `main` @ `a8ce43d`)
**Status:** review

## What changed
- **`apps/cli` (`rea-studio` workspace):** `npm run analyze -w rea-studio -- <app dir | .asar> [--out f] [--max-heap-mb n]`.
  Runs pinned `rea-agents@6.4.0` (a new dependency) with stdout streamed to a temp file and REA's stderr progress
  shown live, converts the result with Codex's `adaptReaFile` (1 GiB cap), writes `<app>.studio.json`, and prints a
  findings summary. Paths resolve from `INIT_CWD`, so relative paths work through `npm run -w`. The temp dir is always removed.
  `preanalyze` builds schema/adapter/CLI. The build lives in a pre-script because Windows `cmd.exe` mangles
  arguments with spaces when they're appended to a script chained with `&&`.
- **`/open` page** (`components/OpenProject.tsx`, `lib/open-project.ts`): drop or choose a `.studio.json`. It's read with
  `File.text()` in the browser (512 MB cap) and shape-checked (schema version, required sections). Raw REA output,
  non-JSON, and the wrong version each get a clear message. Never uploaded; the page is static.
- **`Explorer.tsx` split:** `Explorer({ demo })` now only fetches the demo and renders `ProjectExplorer({ project, title,
  note, actions })`, which has all the previous behavior (URL state, banner, panes). `/open` uses `ProjectExplorer` directly.
  The demo pages behave the same.
- Landing page: "Your own app · local mode" card; honesty bullet updated.
- README "Explore your own app (local mode)" section + `apps/cli/README.md`; ARCHITECTURE.md local-mode diagram.
- Root `package.json` workspaces: added `apps/cli`. Lockfile: `rea-agents@6.4.0` + its deps (`npm audit --omit=dev`: 0 vulnerabilities).

## How to verify
- `npm test -w rea-studio`: 4 tests. They run real REA on the tiny sample and check the output file (schema version,
  findings, **no absolute input paths in the file**), the default output name, and the error/usage paths.
- Root typecheck/build pass; adapter 27, worker 31.
- Manual: CLI on the installed GitHub Desktop 3.6.5 → full, untrimmed project (2,683 nodes, 3,461 links,
  1,777 source files, 4.5 MB) in ~148 s. No local paths in the file. Opened at `/open` via the real file input:
  explorer loads with the "Nothing was uploaded" note. Raw REA JSON, non-JSON and wrong-version files show their messages.

## Not done / known issues
- Not published to npm, so `npx rea-studio` doesn't work yet. Publishing is the human's call (needs an npm account and a name).
- That GitHub Desktop run reported 136 files with resource issues vs 139 in T001: REA's shared budget isn't
  perfectly deterministic under load. Worth noting in the T010 upstream comment if it's ever posted.
- `/open` shareable links only make sense for the person who has the file. The URL state still updates, which is harmless.
