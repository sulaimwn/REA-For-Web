### T010: upstream REA drafts (`docs/upstream/`). Nothing has been posted.
- **New-issue draft:** Electron APIs reached through webpack externals aren't recognized.
  Verified with a minimal repro (`docs/upstream/repro-webpack-electron/`): the same code with
  `const e = require('electron')` gives 1 window / 1 preload / 1 paired handler; in webpack's
  module-factory shape it gives 0 / 0 / 0. GitHub Desktop's minified `main.js` has exactly this shape
  (`4157(e){e.exports=require("electron")}`, `new r.BrowserWindow(t)`).
  Checked against upstream PR #2094 (wrapper *parameters*): it doesn't cover this.
- **Comment draft for PR #2092:** upstream already knows about the shared result budget (#2092,
  #2097 quote the same messages). The draft adds GitHub Desktop as a public, reproducible data point.
