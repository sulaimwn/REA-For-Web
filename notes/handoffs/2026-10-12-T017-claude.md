# T017 — Guided tours (claude)

**Branch:** `claude/T017-tours` (built on `claude/T016-ask` ← `claude/T013-local-mode`; merge those first)
**Status:** review. **No tours are generated yet; that needs the human's API key (a few cents).**

## What changed
- `apps/web/scripts/generate-tours.mjs` (`npm run tours -w @rea-studio/web [-- <slug>]`): runs `askProject`
  (Opus 5.5) on curated questions per demo (tiny-electron 2, github-desktop 3, vscode-core 2; vscode is skipped
  until T014 merges) and writes `apps/web/tours/<slug>.json` with `projectId`, the answers, citations and
  steps. It refuses to run without `ANTHROPIC_API_KEY` and prints per-question and total cost.
- `build-demo-projects.mjs`: publishes `public/projects/<slug>.tours.json` only when the tour's `projectId`
  matches the current project (node ids change with the fixture/adapter). Stale files are skipped with a warning.
  Adds `tours` (count) to each index entry.
- Web: `DemoEntry.tours`, a `Tour` type; the demo `Explorer` fetches tours when the count > 0 and passes them through
  `ProjectExplorer` to `AskPanel`. The Ask tab lists "Guided tours · no key needed" above the key form. Opening one
  shows its recorded steps and answer (clickable nodes) and switches the graph to the cited nodes.
- `apps/web/tours/README.md`: how to (re)generate; don't hand-write tours.

## How to verify
- Root typecheck and build pass.
- Browser with a temporary, clearly labeled test tour file (deleted, never committed): tour listed without a key;
  opening it showed steps + answer and the graph switched to the 2 cited nodes. No app console errors (only dev HMR
  socket noise from the server restart).
- Generator without a key exits with the message; a tour file with a wrong `projectId` is skipped with the
  regenerate hint.
