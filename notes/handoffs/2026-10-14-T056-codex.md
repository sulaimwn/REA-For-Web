## What changed

The human's latest brief prioritizes public uploads today and splits launch from
Turnstile setup. This source implements that split: `PIPELINE_PUBLIC_UPLOADS=1`
opens bounded hosted disk admission; `PIPELINE_TURNSTILE=1` is a separate,
default-off later rollout. No widget/account/credential action blocks release 1.

- `PIPELINE_STORAGE=local`, `PIPELINE_HOSTED_LOCAL=1` permits the dedicated HTTPS
  deployment, keeping ordinary development's loopback-only check. Hosted mode
  requires the existing private owner key and a separate upload signing secret.
- Public mode requires trusted proxy/network quotas. It rejects R2, missing
  hosted mode, incomplete quota configuration or unsafe HTTP origin. Visitor
  tickets need no invite; owner keys can bypass only the network quota. Public
  ceilings are **3/network/day, 25/day, 500/month**; both owner and pre-analysis
  use the same global counters and 20 total pending slots.
- New HostedLocalStore uses the existing local signed/byte-verified file route,
  cache namespace and result serialization. Its startup/admission check accepts
  only a private ext4 filesystem **<=64 GiB**, with service ownership/mode 700;
  refuses root disk/tmpfs and stops admission below **13 GiB free**. Final hard
  capacity is the filesystem, not a Redis storage ledger. Results <=128 MiB.
- File links validate their signature before an atomic one-use Redis claim;
  at most two body transfers. Claims and consumed-link keys expire conservatively,
  body deadline ten minutes, failures remove partial files and release the slot.
  The ticket capacity lease is extended across transfer. Replay cannot write
  a second file; retry needs a new ticket. Trusted pre-analysis uses these same
  transfer claims too.
- Completion in public mode keeps exact Origin plus the existing private job
  bearer token, without a beta key/second challenge. Result access stays private.
  No UploadRequest/Ticket/JobStatus/StudioProject/cache field changes.
- Caddy allows 512 MiB only on PUT `/api/uploads/<id>/file`; other requests retain
  1 MB. Socket-peer header ownership, enforced HSTS/nosniff, resource limits remain.
- Added local env/Compose/mount/systemd drop-in examples and exact migration /
  rollback procedure in `docs/public-disk-uploads.md`. Web gets only the object
  mount, never Docker or staging; queue drop-in adds only objects to its existing
  writable paths. Logs bounded; no sandbox/CPU/memory/time limit increases.
- Optional future Turnstile validates exact hostname/action with bounded token,
  response and 5 s full deadline; no redirects/IP disclosure/provider logging.
  Production config rejects test keys. Form exposes only the site key, loads the
  official widget after hashing, handles cancellation/expiry/load failure and
  always renders a fresh check. **Flag off** means no widget network request.
  Public form labels the owner key optional even when Turnstile stays off.
