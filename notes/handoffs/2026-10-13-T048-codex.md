## What changed

- Add case-insensitive `.macho` and `.dylib` filename admission, both canonical
  `macho`. They reach the independently approved T035/R009 native worker as
  `target.macho`, after the existing size and SHA checks. Extensionless names,
  `.app`/`.ipa` bundles and versioned `.dylib.1` names remain outside this path.
- Raw storage, signed R2 keys and expiry/partial-file cleanup cover `macho`.
  Revision 7 gains an isolated `macho` result namespace; existing kinds and
  historical authorized ASAR results retain their cache identities.
- Cache lookup still happens only after every downloaded byte is verified.
  Uppercase aliases can reuse identical analyzed bytes, without exposing a
  result through a claimed hash or another parser's cache.
- The authorized job supplies its own display filename. Shared cached project
  labels stay canonical. The form, local-open instructions, landing format list,
  metadata and support/setup docs now include thin macOS programs.
- New separate `test:macos` HTTP check needs a local checksum-verified public
  jq file and isolated loopback services. It downloads nothing and never runs
  the supplied program. The ordinary two-suite HTTP/hosted check stays intact.
- Worker, collectors, adapters, schema, request/response fields, tokens, quota,
  resource/output/time limits and global concurrency were not changed.
