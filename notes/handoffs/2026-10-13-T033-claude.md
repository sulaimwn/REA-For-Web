# T033 — Landing page refresh (claude)

**Branch:** `claude/T033-landing` (from main @ `41e505f`)
**Status:** review.

The human wants uploading their own apps to be the product's main point. The landing page still described only
Electron and .NET, and buried the way to try your own app below the spec list.

## What changed
- **Intro:** describes every supported kind (Electron, Windows/Linux programs, Android) in plain words.
- **"Try your own app" right under the intro:**
  - when uploads are configured: **Upload your own app**, plus a note that local analysis also works;
  - otherwise: **Map your own app** → `/open`, plus "analyze it on your own machine with the free CLI… nothing is uploaded".
  - The old upload button below the spec list is gone, since it duplicated this.
- **"Reads" row:** lists all formats (`.asar`/folder, `.exe`/`.dll` .NET or native, `.elf`/`.so`, `.apk`, websites locally).
- **`/open` instructions:** list every format the CLI reads and what each needs (`GHIDRA_INSTALL_DIR`, `REA_JADX_MCP_JAR`, a URL).
- **Demo picker:** two labeled tab groups, "Samples with known answers" (`tiny-*`) and "Real apps".
  - There are 11 demos once T031 merges.
  - At phone width each group stacks label over tabs, the tab row scrolls, and the page never scrolls sideways.
- The "Ask" row is untouched here. T030 updates it for the free tier.

## How verified
- Web typecheck passes, web tests pass, and the production build passes.
- **Browser, 1280 px:** checked the text structure (intro, try button and note, Reads row, two demo groups); no horizontal overflow.
- **Browser, 375 px (mobile emulation):**
  - Found and fixed a flex `min-width` issue that made the page lay out at 637 px.
  - After the fix: page width 375 = scroll width; intro, spec and specimen sit at 16–359 px.

## Interface changes or questions for the other agent / human
- **Codex:** UI-only, please review. It touches `page.tsx`, `LandingDemo.tsx`, `OpenProject.tsx` and `globals.css`. There are no API or schema changes.
