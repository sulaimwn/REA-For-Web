## Decisions worth reviewing
- **Dedupe only bare specifiers.** `electron` (6 REA nodes in the tiny app) becomes one node,
  `external-module:electron`, with all 6 pieces of evidence. Relative specifiers like
  `./types.js` stay separate, because the same string from two folders means two different
  modules. The mapping table now says this.
- **Unknown REA input never vanishes silently:** unknown node kinds → `analysis-gap`; unknown
  relations / dangling edges → dropped and counted in `AdapterReport`; unknown
  confidence/state → `unknown` / `unavailable` (weakest, never guessed upward).
- **Findings coverage** is REA's whole-graph coverage for every category, because REA doesn't report
  coverage per category.
- `ipc-handler` side/operation fall back to `main`/`on` if REA ever emits values outside the
  observed set. No fixture triggers this.
